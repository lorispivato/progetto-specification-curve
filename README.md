# Specification curve analysis

La presente repository contiene il codice e i dati legati al lavoro **Analisi di robustezza di uno studio sull’allineamento cognitivo**, svolto per il corso di _Psicometria per le neuroscienze cognitive_ dell'Università di Padova durante l'anno accademico 2026/2027.

La repository è così strutturata:
* `code` contiene il codice in R di tutta l'analisi e dei grafici prodotti;
* `data` contiene i dati di partenza necessari per eseguire il codice;
* `figures` contiene i grafici prodotti dal codice in R e inclusi nel report finale.

`report.pdf` è il report finale del lavoro svolto.
